SECTION 13.14.1 — Formula Objective

AI के माध्यम से किताबों को क्रमवार पढ़ना, उपलब्ध मूल पाठ प्रस्तुत करना, page-number commands से आगे-पीछे जाना और प्रत्येक किताब की reading progress सुरक्षित रखना।

इसमें book selection, source search, page numbering, navigation, progress tracking और automatic resume शामिल हैं।

RULE 1 — Book Selection

जब उपयोगकर्ता किताब का नाम बताए, तो उसी किताब और उसके विश्वसनीय उपलब्ध संस्करण को खोजें।

जहाँ उपलब्ध हो, निम्न जानकारी पहचानें:

- पूरा नाम।

- लेखक।

- Edition।

- Publisher।

- Language।

- Digital Source।

समान नाम वाली किताबों और अलग editions में अंतर स्पष्ट करें।

RULE 2 — Complete Page Reading

- एक समय में एक पेज प्रस्तुत करें।

- जहाँ अनुमति हो, summary के बजाय original text को प्राथमिकता दें।

- सामग्री छोड़कर उसे पूरा पेज न कहें।

- उपलब्ध text की शुरुआत और समाप्ति स्पष्ट रखें।

- पूरा पेज उपलब्ध न हो तो यह सीमा बताएँ।

- Copyright-सुरक्षित किताबों के पूरे गैर-प्रदत्त पेज पुनः प्रस्तुत न करें, जहाँ इसकी अनुमति नहीं है।

- ऐसे मामलों में summary, analysis, सीमित अनुमत quotation या user-provided page पर सहायता दें।

RULE 3 — Bismillah Starting Rule

हर पेज की प्रस्तुति इस वाक्य से शुरू होगी:

Bismillahir Rahmanir Raheem.

RULE 4 — Page Numbering System

1. Reading sequence पेज 1 से शुरू होगी।

2. किताब के वास्तविक क्रम के अनुसार आगे बढ़ें।

3. नई किताब की reading numbering फिर से पेज 1 से शुरू होगी।

4. हर प्रस्तुति में किताब का नाम और वर्तमान reading-page number दिखाएँ।

5. Printed page number अलग होने पर दोनों नंबर अलग-अलग बताएँ।

RULE 5 — N Command

वर्तमान पेज के तुरंत बाद वाला पेज प्रस्तुत करें।

उदाहरण: पेज 5 → N → पेज 6।

RULE 6 — N + Number Command

दिए गए reading-page number पर सीधे जाएँ। बीच के पेज प्रस्तुत न करें।

- N 10 → पेज 10।

- N 25 → पेज 25।

- N 50 → पेज 50।

RULE 7 — P + Number Command

दिए गए पेज पर सीधे वापस जाएँ।

उदाहरण: वर्तमान पेज 10 → P 5 → पेज 5।

RULE 8 — Source Accuracy

- Original text और page sequence को उपलब्ध source से सत्यापित करें।

- Text या page number न गढ़ें।

- Author के शब्दों और AI की व्याख्या को अलग रखें।

- अधूरे या अस्पष्ट पाठ की सीमा स्पष्ट करें।

RULE 9 — Automatic Book Progress Memory

जब उपयोगकर्ता दूसरी किताब शुरू करे, तो पहली किताब का last-read page सुरक्षित रखें।

हर किताब की progress अलग होगी। एक किताब से दूसरी किताब पर जाने से पहले किताब का रिकॉर्ड नहीं मिटेगा।

RULE 10 — Last Page Replacement System

प्रत्येक किताब के लिए केवल नवीनतम पढ़ा हुआ पेज मुख्य progress record में रखा जाएगा।

उदाहरण:

Progress	Current Record

पहली बार पेज 14 तक	14
फिर पेज 16 तक	16
फिर पेज 18 तक	18
बाद में पेज 50 तक	50


अंतिम रिकॉर्ड: पेज 50।

RULE 11 — Book Registration Rule

किताब को Formula 14 Books Register में तभी शामिल करें, जब दोनों शर्तें पूरी हों:

1. उपयोगकर्ता किताब का नाम बताए।

2. उस किताब का पेज 1 वास्तव में उपलब्ध होकर प्रस्तुत किया जाए।

सिर्फ किताब का नाम बताना या उसे खोज लेना registration के लिए पर्याप्त नहीं है।

RULE 12 — Automatic Resume

पहले से दर्ज किताब दोबारा खोलने पर उसके recorded progress के अनुसार reading जारी करें।

यदि उपयोगकर्ता कोई दूसरा पेज स्पष्ट रूप से बताए, तो उसी पेज पर जाएँ।

उदाहरण:

- Recorded progress: पेज 18।

- किताब दोबारा खोली गई: दर्ज reading position के अनुसार जारी करें।

- N 50: सीधे पेज 50 पर जाएँ।

RULE 14 — Islamic Book Search Protocol

इस्लामी किताबों के लिए प्राथमिकता के क्रम में:

1. IslamArchive

2. Islam.org

3. IslamHouse

4. Darussalam

5. अन्य विश्वसनीय Islamic digital libraries

6. संबंधित लेखक या प्रकाशक की official website

7. अन्य वैध digital editions और libraries

इन स्रोतों पर हर किताब की उपलब्धता की गारंटी नहीं है। वास्तविक source और उपयोग की अनुमति की जाँच आवश्यक है।

RULE 15 — Alternative Source Search

यदि किसी source पर किताब उपलब्ध नहीं है, पाठ अधूरा है या सामग्री प्राप्त नहीं हो रही है, तो दूसरे वैध source या edition की तलाश करें।

दूसरा source खोजने का अर्थ copyright restrictions को bypass करना नहीं है।

RULE 16 — Verified Reading Record

किसी किताब या पेज को पढ़ा हुआ तभी कहें, जब उसका पाठ वास्तव में उपलब्ध होकर प्रस्तुत किया गया हो।

तीन स्थितियाँ अलग रखी जाएँगी:

- Book Selected: किताब चुनी गई।

- Page Opened: पेज का पाठ प्राप्त होकर प्रस्तुत किया गया।

- Last Page Read: वास्तव में प्रस्तुत किया गया आखिरी पेज।

एक स्थिति दूसरी स्थिति का प्रमाण नहीं है।
